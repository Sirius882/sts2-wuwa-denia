# 达妮娅代码动画目录与内测卡

2026-11-15，v4.1.2（未发布）。以 `Denia*Visual`、`DeniaSingleHitAttackPatch`、`DeniaFormOverlaySync` 当前实现为准。单位均为秒，小数保留三位；Fast 指设置中的“快速”，动作三倍速。表内时间为动画自身的理想时间轴，不是整张卡牌完成时间：引擎帧间隔、原伤害回调、目标特效、死亡结算或其他牌效可额外延长。

## 实际触发与完整播放时间

|---|---|---:|---:|---|

“整套”是粉态正放起身＋攻击＋倒放坐回，起身没有同时叠放旧人物。多段牌一张只启动一次身体动作，群攻每轮对多个敌人的同段伤害共用命中点，不按怪物数量重复动作。牌来自达妮娅、其他角色、遗物或模组均可；只要求出牌者角色为达妮娅且牌类型为攻击。技能／能力牌的伤害、反伤和其他无对应攻击牌的伤害不会触发。

当前判段读取本牌首个 `AttackCommand` 的 `_hitCount`，不预测联动追加、不把多个独立命令相加、不按实际命中的敌人数计段。若某牌把多次伤害写成多个独立单段命令，目前会按首个命令的1段选择；这是当前实现边界。非交互模拟不播放视觉，也不加动画等待。

点击泡泡还要求战斗为活动状态、未暂停／结束、战斗屏幕为当前屏幕，且不处于出牌拖动、选牌或选目标。可响应点击的UI及其父级会排除；其他角色不会因队友是达妮娅而得到泡泡。

## 命中卡点与“卡手”

以下均从该牌身体动画起播时算起，**粉态已经包含正放起身**。数值是累计到达时间，不是每段另等这么久。

| 动作 | 普通：伤害数字命中点 | 快速：伤害数字命中点 | 动画本身最长必须等到 |
|---|---|---|---|
| 粉态单段 | 5.166 | 1.722 | 首击 |
| 粉态多段 | 4.638、5.305 | 1.546、1.768 | 第二击；后续伤害不等动作 |
| 黑态单段 | 0.826 | 0.275 | 首击 |
| 黑态二／三段 | 0.732、1.464 | 0.244、0.488 | 第二击 |
| 黑态四段以上 | 0.988、1.878、2.570、3.262 | 0.329、0.626、0.857、1.087 | 第四击 |

伤害前回调和目标命中特效均经门控同步。若原伤害回调尚未准备好，角色会在该命中姿态保持，直到原回调继续；这会把实际完整播放拉长。表内完整时长以没有保持为前提。

攻击结算只等命中任务，不等待整段 `Finished`。原版牌效／队列仍可能占用操作，不能据此承诺“命中后立即能点下一张”。未完成的收招可被下一次攻击重播、切形态、死亡、复活或场景卸载结束；这些路径会释放旧命中等待，避免挂死。旧防御后撤及其受击／减益补丁已删除，新攻击不会再被旧后撤路径打断。

**最容易感觉卡手的是普通粉态**：每次新攻击都先等3.083秒起身，单段首击到5.166秒；快速分别缩为1.028秒和1.722秒。粉态多段总演出虽长达20.829秒，结算不等后面约15.525秒的收招／坐回。

## 其他演出与静态状态

- 三级集谐处决：由公开共鸣破坏规则触发，目标集谐偏置至少3层、存活且无 `IllusionPower`。不限制粉／黑形态。进入0.800＋视频4.567＋冲击0.267，等待到 **5.633** 秒放行原伤害；视觉退场到 **6.133** 秒，音轨尾音最长到 **8.367** 秒。普通／快速均原速，输入遮罩在放行时移除。该演出仍含视频／音轨，外层泡泡、滤镜与冲击为代码表现，不属于角色实时身体动画。
- 选人背景：原MP4 397帧／60FPS，约 **6.617秒／轮**，Windows走硬件解码；其他平台／硬件失败走OGV兼容路径。只在选人页播放，不占战斗卡牌等待，不放进战斗动画测试卡。
- 粉黑切态为直接切换，没有变形动画或额外等待。死亡直接显示静态能量图，复活恢复当前待机，均无旧死亡动画；原版自身死亡流程可能另有等待。
- Instant 不是本表的Fast：代码目前只将 `FastModeType.Fast` 视为三倍速，Instant 下身体动作仍按原速门控；处决也固定原速。这次仅整理与清理，没有擅自更改该设置语义。

## 内部动画测试卡

战斗控制台输入 `card DENIA-DENIA_ANIMATION_TEST`。0费技能／Token／自身，隐藏于卡库、不随机生成、不可升级，正常打出后弃置；重复测试可再获得一张。

每页最多三个选项，始终显式选中后才播放，共14个叶子选项：

- 粉色形态：待机；起身／坐回 → 正放、倒放；粉态攻击 → 单段、多段。
- 黑色形态：待机；备用起身；黑态攻击 → 单段、二／三段、四段以上。
- 其他演出：泡泡 → 粉色点击、黑色点击、地图落笔；三级集谐处决。

测试借用生产视觉与时钟，攻击包含粉态前后衔接，但不创建攻击／伤害命令、不改变真实形态或任何战斗数值。待机只播一轮，单个起身／倒放独立播放；泡泡保留身体显示。普通／快速遵循上表，内测卡**故意等待整个所选身体／粒子演出**以便观察，不能把测试卡的等待误认为正常攻击阻塞。处决复用原入口，等5.633秒放行，退场与尾音继续。

测试选择的相反形态只改变临时画面，完成后恢复原形态待机。战斗卸载／死亡释放预览等待。测试不产生模拟伤害数字；挥动与真伤害数字卡点需使用对应段数的实际攻击牌验收。

## 清理范围与复用入口

旧帧图集／挥砍贴图此前已从运行时删除。本次进一步删除旧slash／pulse驱动、0.2秒强化兼容入口与等待、旧呼吸整体缩放、旧死亡过渡状态、旧后撤补丁以及7个旧Blender帧动画制作脚本。Git历史保留回退能力，不新建备份分支。原始美术档案不因运行时清理而删除；处决视频与选人背景及兼容OGV均仍有用途，保留。

场景加载所需的单帧首姿仍保留作占位，它直接引用新版代码动画首帧，运行后隐藏／暂停；不是旧动画回退。角色主体仍用裁片＋光流GPU插值，粒子与攻击特效实时演算；不是逐帧播放视频。
